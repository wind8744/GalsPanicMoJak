이 폴더에 PNG 또는 JPG 파일을 넣으면 숨겨진 그림으로 사용됩니다.

- 파일 이름 순서(대소문자 무시)로 1스테이지부터 차례로 쓰이고, 파일 수보다 스테이지가 많으면 처음부터 다시 돕니다.
  예) 01.png, 02.png, 03.jpg
- 보드 비율은 4:3 (120x90 칸) 입니다. 비율이 다르면 가운데를 기준으로 잘라서 꽉 채웁니다.
- 칸 단위로 다시 샘플링되므로 세부가 뭉개집니다. 큰 형태와 색 대비가 뚜렷한 그림이 잘 보입니다.
- 파일이 하나도 없으면 스테이지마다 다른 풍경을 절차 생성해 사용합니다.
- 이 저장소는 공개 저장소입니다. 이미지를 커밋하면 GitHub에 그대로 공개되니, 올리고 싶지 않은 이미지는
  .gitignore 에 `Assets/StreamingAssets/HiddenImages/*.png` 등을 추가해 제외하세요.
